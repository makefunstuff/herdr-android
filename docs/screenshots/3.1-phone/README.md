# Shepherdr 3.1 on a phone, as the reference

Shots of the Shepherdr 3.1 web app the app is measured against, at the phone's size
(390×844, dark and light), taken read-only from the service on this machine
(`127.0.0.1:7788`, see `docs/web.md` in `/data/jpl/shepherdr-3.1`). Nothing was sent,
accepted, started or changed while taking them; they show the person's own data.

They are reference material for the app's UI work (HERD-31), not app screenshots:
`drawer` (the spaces drawer), `assistant-chat` (a space's Assistant), `tasks` (the
tasks list with its filters), `task-light` and `task-accept-dark` (a task's tabs, and
the Accept card), `task-chat-dark` (a task's chat), `artifacts`, `settings`.
